# Pocket Patch

Pocket Patch is a personal finance web application currently in development that helps users track spending habits and identify savings opportunities.

The goal of the application is to support users in making more informed financial decisions by allowing them to log expenses and monitor progress toward savings goals.

This project is being built as a learning experience while exploring software development concepts such as front-end layout, debugging, version control using GitHub, and future SQL database integration.

 MVP Features
- Track spending entries
- Monitor savings progress
- View logged financial data

Additional features are planned as development continues.
